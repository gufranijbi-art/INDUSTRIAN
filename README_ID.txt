INDUSTRIAN — Proyek Game Android 3D
==================================

Ini adalah SOURCE PROJECT Android, belum berupa APK yang sudah dikompilasi.

Cara membuat APK:
1. Instal Android Studio di komputer.
2. Buka folder INDUSTRIAN_Android_Project melalui Android Studio.
3. Tunggu Gradle Sync selesai (internet diperlukan pertama kali untuk mengunduh Android Gradle Plugin).
4. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK debug akan dibuat di:
   app/build/outputs/apk/debug/app-debug.apk

Kontrol:
- Joystick kiri: bergerak
- LOMPAT: melompat
- KAMERA: mengubah sudut kamera

Persyaratan:
- Android Studio versi yang mendukung Android Gradle Plugin 8.6.1
- Android SDK Platform 35
- JDK 17

Catatan:
Prototipe ini menggunakan OpenGL ES 2.0 native untuk menggambar lingkungan 3D dasar.
